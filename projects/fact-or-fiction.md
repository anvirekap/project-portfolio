# Fact or Fiction

## Overview

Fact or Fiction is a real-time multiplayer party game where 2–8 players join a room using a shared room code and play from separate devices. One player serves as the source each round and sees the correct answer to a trivia question, while the remaining players submit believable fake answers. Everyone votes on the answer they think is true.

The game combines trivia, bluffing, and social deduction mechanics in a lightweight browser-based experience.

## Features

- Room-code multiplayer system
- Support for 2–8 players
- Real-time game state synchronization
- Rotating source player each round
- Decoy submission and voting system
- Automatic score tracking
- Shared-win support for tied scores
- Mobile-friendly design
- Public deployment
