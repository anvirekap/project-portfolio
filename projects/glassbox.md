# GlassBox

[Shared team repository](https://github.com/Ghaz-555/Hackathon)

Hack the Hill III team project: an interactive way to see inside a language model.

## Project features

- Character-level predictions with probability distributions.
- Temperature controls and seeded text generation.
- Training and held-out loss charts.
- Attention and model-operation visualizations.
- The current shared repository also includes a 3D architecture explorer and a GPT-2 embedding explorer.

## Stack

Python, NumPy, FastAPI, React, TypeScript, Three.js.

## Collaboration

This is a collaborative project hosted in a teammate's repository. Repository-wide features describe the shared application, not a claim that I independently authored every component.
