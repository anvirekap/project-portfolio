## Adding future projects

1. Create or select the project's source repository.
2. Copy [the project template](templates/project-template.md) into `projects/<project-name>.md`.
3. Fill in its purpose, implemented features, stack, source link, and your contributions.
4. Add a row to the featured-projects table above.

Only add a live-demo link once the deployment is available. Clearly identify team projects and individual contributions.
